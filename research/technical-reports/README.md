# Technical Reports

This directory is reserved for detailed engineering and architecture reports.

Technical reports may document:

- platform architecture
- engineering decisions
- testing strategies
- integration models
- data quality approaches
- lessons learned from applied systems work

## Reports

| Report | Focus |
| --- | --- |
| [Platform Architecture and Research Map](platform-architecture-and-research-map.md) | Cross-platform architecture themes, research tracks, and publication guardrails |

Reports should avoid proprietary source code, credentials, private schemas, and customer-specific information.
