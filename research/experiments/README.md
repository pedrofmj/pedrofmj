# Experiments

This directory is reserved for experiment definitions, methods, and results.

Each experiment should include:

- objective
- hypothesis
- related platform
- method
- variables
- evaluation metrics
- results
- limitations

Experiments should use public, synthetic, or properly anonymized data only.
