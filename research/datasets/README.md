# Datasets

This directory is reserved for public, synthetic, or anonymized datasets connected to research work.

Each dataset should include:

- purpose
- provenance
- license
- data dictionary
- collection or generation method
- limitations
- related platform
- related paper, report, or experiment

No private customer data, credentials, or sensitive operational records should be stored here.
