# Galaxy Screenshots

This directory contains public-safe Galaxy visuals.

- `workstation-topology.png` is the supplied topology screenshot showing a personal music workstation and its connected devices.
- `agent-network-sanitized.png` shows the sanitized Agent Network console with generic workspace, host, and project labels.

The original agent-console screenshot was sanitized before publication by
replacing local paths, project labels, host names, and session metadata with
generic stand-ins.
