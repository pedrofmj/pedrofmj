# Galaxy Screenshots

This directory contains public-safe Galaxy visuals.

- `workstation-topology.png` is the supplied topology screenshot showing a personal music workstation and its connected devices.
- `agent-network-sanitized.png` shows the Agent Network overview with generic workspace, host, and project labels.
- `agent-network-permission-queue.png` shows explicit operator review of pending agent permissions.
- `agent-network-code-review.png` shows an agent-assisted code review with changed files and test output.

All Agent Network visuals use generic labels and sanitized metadata. They do not
represent a specific customer, organization, repository, or deployment.
