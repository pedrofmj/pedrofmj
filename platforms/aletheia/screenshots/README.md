# Aletheia Screenshots

This directory contains sanitized screenshots captured from the public Aletheia production portal and Web UI using a synthetic demo flow.

## Captured Files

- `01-public-soon.png` - public Aletheia release page.
- `02-register-request-access.png` - portal access request form.
- `03-register-submitted.png` - access request submitted confirmation.
- `08-aletheia-web-ui-login.png` - Aletheia Web Workbench sign-in screen.

## Remaining Capture Requirement

The authenticated dashboard, marketplace, application launcher, dedicated Matrix root, and workbench operation screenshots require one of these production-safe access paths:

- a valid production portal administrator account to approve the synthetic user and grant the Aletheia Web UI module; or
- an already-approved synthetic demo account with Aletheia Web UI access.

Only add images that do not expose proprietary source code, private data, credentials, customer information, or raw access tokens.
